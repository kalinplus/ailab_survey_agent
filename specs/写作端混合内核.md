# S2 写作端混合内核（骨架模板 + 正文 LLM grounded）

Status: dispatching (2026-09-03)

## Motivation

评测 v2 首跑（`output/survey_eval_report.md`，2026-09-02）暴露的工件缺陷全部集中在
`tools/write_survey.py`（纯模板填充，零 LLM）：

- 小节相似度 max 0.952：每节同一段"横向比较这些工作…"逐字相同。
- harness 元话语泄漏进正文（"C 模块在这里采用降调写法""本节只使用 CitationReadySet 中的论文"）→ L1.5 未引用句 weak/unsupported 的组成部分（support rate 0.297）。
- 节首句 `{title} 这一部分关注的问题是：{goal}…[{first_cite}]` 无条件挂引用 → eval 中 4 条 unsupported 引用全是这类句子。
- 选文塌缩（`_build_section_claim_plan` write_survey.py:134-176）：轮转偏移只有 2，global top 几乎每节都进 `selected[:5]`，模板又重点引 first/second cite → 84 处引用仅 3 个唯一 id；类目桶 miss 时整节退化为全局 top（PCG 论文出现在 Latent Architectures 节）。
- 开放挑战 / 未来方向整段硬编码、零引用。

用户已拍板：混合内核——骨架（节标题 / 图表槽 / 引用白名单）保持确定性模板，
正文段（综述句、比较句、局限句）用 Intern-S2 在证据约束下生成，模板做兜底。

## Boundary（触达文件）

- `tools/write_survey.py`（主体）
- `tests/unit/test_c_tools.py`（或其内新增用例；不建新测试文件）
- **不碰**：`tools/phases/`、`tools/verify_citations.py`、`tools/revise_survey.py`、
  `harness/goal_gate.py`、`harness/agents/`（只读复用 `relevance.py` 允许）、
  `PROGRESS.md`、`specs/`。

## Interface Contract

- `run(request_path)` 对外签名与 request schema 不变（tool_registry / A 模块无感知）。
- LLM 注入模式沿用 repair_agent 的 callable 注入：内部按
  `EVISURVEY_WRITER_LLM=1`（默认 off，off = 今天的行为逐字不变）惰性构造
  `llm_client.InternS2Client`，逐节传入 `llm.chat` callable。
- 反幻觉红线（CLAUDE.md）：生成句只允许复述/改写随 prompt 提供的证据片段与
  paper card 字段，不得引入未提供的数字、结论、年份；引用 id 只能来自该节
  `allowed_paper_ids` 白名单。
- 降级边界：单节 LLM 失败 → 该节回退模板路径并记日志，**不 abort 整篇**
  （这是交付行为级 degradation，属于边界允许的降级；其余异常照旧冒泡）。

## Slices（每个切片独立可验收）

1. 选文修复（纯确定性，无 LLM）：节间去重 + 按相关性分派
   （复用 `harness/agents/relevance.py` 的 bge / keyword fallback，无网络）。
2. 模板净化（无 LLM）：删元话语、节首句要么落地证据要么不挂引用、
   开放挑战/未来方向改为从 evidence_store 取句子 + 引用。
3. LLM 正文段（混合内核落地）：综述/比较/局限三段走 LLM，
   prompt 携带该节 selected papers 的 card 字段 + evidence 句窗口；
   fallback 到切片 2 的模板输出。

## Acceptance Criteria（unit，fake LLM，无网络）

1. `EVISURVEY_WRITER_LLM` off：输出与当前实现逐字兼容（既有测试全绿，行为不回归）。
2. 选文：构造 ≥5 类目 × ≥15 张 cards，断言任意两节 `selected_papers` 重叠 ≤ 2/5；
   且每节 selected 对该节 category 的 relevance（keyword fallback 计算）不为该节
   全局垫底（防 PCG-错配复发）。
3. 净化：输出正文不含元话语禁词（"C 模块""CitationReadySet""降调写法"等，
   以常量禁词表断言）；开放挑战/未来方向节至少含 1 个合法引用 id。
4. LLM 路径：注入 `tools/clients/llm_fake.py` 后逐节走 LLM；断言生成句中的
   引用 id ⊆ 该节白名单；fake 抛异常时该节回退模板且整篇仍产出。
5. `pytest tests/unit/` 全绿。

## Real-API Acceptance（S0，主会话合并后做，不在本 worktree）

四层复测目标：L0 max sim < 0.8；零引用正文节 = 0；L1.5 support rate ≥ 0.5；
L1 precision ≥ 0.8；L3 informational/guidance 不再因引用塌缩/复述扣分。
