# T1 搜索引导与白名单选择（gold 对齐回退的检索侧修复）

Status: dispatching (2026-09-04 晚)

## Motivation

S0 四层评测（`output/survey_eval_report.md`）：system-in-gold 0.583→0.118、
gold recall 0.033→0.018。规模公平的 in-gold 也大跌说明真信号是：live 检索
没捞到领域经典文（Ha 世界模型、Dreamer 系、MuZero 等 staples）。三个缺口：

1. P2 读着 7 篇种子综述，但 expansion 只提炼 23 条主题查询——**种子综述的
   高频参考文献本身没被当作检索目标**（现成的领域对齐"伪 gold"浪费了）。
2. 查询族全是 aspect 关键词拼接，没有 landmark/highly-cited 查询；
   influence 引用数过滤只在旧年份段生效。
3. 去重只按 DOI——同文预印本/多版本不合并，标题模糊去重缺失。
4. 白名单（`citation_prelock.py`）纯按年份降序截断，经典老文被挤出。

## Boundary（触达文件）

- `tools/phases/phase2_survey_analyzer.py`（种子综述参考文献 → expansion 候选）
- `tools/phases/phase3_paper_retriever.py`（landmark 查询族 + 标题模糊去重）
- `harness/citation_prelock.py`（白名单选择：recency × influence 混合）
- 对应既有测试文件（`test_phase2.py` / `test_phase3.py` 等，不建新文件）
- **不碰**：`tools/write_survey.py`、`tools/evaluate_survey.py`、
  `PROGRESS.md`、`specs/`。

## Slices

1. P2：从种子综述骨架提取高频参考文献（标题/作者/年份），并入 expansion
   候选（与现有 23 条主题查询并存，标记 `source=bib`）。
2. P3：每 aspect 的查询族追加 1 条 landmark 变体（aspect + "survey|review"
   或引用数过滤、无新年份窗）；`dedup()` 增加标题规范化模糊去重
   （小写/去标点/去版本后缀，Jaccard 或前缀匹配即可，不引入新依赖）。
3. 白名单：排序从纯 recency 改为 `survey_ref_count`/citation 信号与年份的
   混合分（如 `0.5*norm_year + 0.5*norm_influence`），默认行为在
   pool ≤ cap 时不变形。

## Acceptance Criteria（unit，fake API，无网络）

1. P2：给含已知参考文献列表的种子综述，断言产出含 `source=bib` 的候选且
   高频文献优先。
2. P3：构造两组 DOI 不同、标题相同的候选，断言去重后留 1；默认旋钮下
   现有去重/排序行为不回归（既有测试全绿）。
3. 白名单：构造新旧混合 pool，断言 cap < pool 时经典高影响文不被纯年份
   挤出；pool ≤ cap 时集合与旧实现一致。
4. `pytest tests/unit/` 全绿。

## Real-API Acceptance（S0 下轮真跑，主会话）

in-gold 回升（≥0.3 起步）；staples 命中清单非空；L2' coverage 维持 1.0。
