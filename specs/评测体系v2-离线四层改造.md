# 评测体系 v2：离线评测四层改造

状态：spec 已确认（2026-09-02），待实现。
定位：**交付质量背书**——指标体系完整性、可展示性、学术依据优先，不追求 run 间敏感性。

## 动机

现有三层离线评测（`tools/evaluate_survey.py` + `scripts/run_survey_eval.py`）的问题：

1. **Layer 1（NLI 引用核查）与线上 verify/goal_gate 同源同预算级**，信息重复，作为质量信号价值低（实际是回归护栏）。
2. **Layer 2（gold reference recall）依赖同主题 ground truth**，新领域不可用；且 DeepSurvey-Bench (arXiv 2601.15307) 指出按引用数/结构连贯选 gold 本身不可靠。
3. **Layer 3（单 judge 七维绝对打分）** self-preference 偏置（Intern-S2 评自己生成的文本），跨 run 不可比。
4. **盲区：citation_coverage ≈ 0.4–0.5，过半正文句子无任何事实性核查**。

参考文献：ReportBench (arXiv 2508.15804，未引用 claim 用外部检索验证)、DeepSurvey-Bench (arXiv 2601.15307，学术价值三维 rubric)。**明确不做**：AHA adversarial judge（不适合本场景）、pairwise baseline 对比、SurGE benchmark 跑分。

## 改造范围

- `tools/evaluate_survey.py`：新增四层函数；`render_md` 重组为四个区块。
- `scripts/run_survey_eval.py`：接线新层 + 新 flags。
- `tests/unit/test_evaluate_survey.py`：新增四层正例测试；`llm_judge` 相关断言按新三维契约改写；citation_quality / reference_coverage / ab_comparison 存量断言必须保持绿。
- 不改生成侧 pipeline（verify_citations / goal_gate / revise 不动）；不引入新第三方依赖（embedding 用现有 `EmbeddingScorer`，NLI 用现有 `NLIVerifier`，检索用现有 `sciverse_client.agentic_search`）。

## 四层设计

### L0 `deterministic` — 确定性画像（零 LLM、零网络）

- **freshness**：引用 id → 年份映射来自综述自带 References 段（格式 `paper:<doi>: <title> (YYYY).`）；语料年份分布来自 `--papers`（paper_cards，含 year 字段）。指标：引用年份中位数、语料年份中位数、两者的 offset、引用集合近两年（≥ 当前年-1）占比 vs 语料近两年占比。解析不出年份的引用计入 `years_unresolved`，从分子分母中剔除。
- **structure**：小节字数均衡度（字数的标准差 / 均值）、每节 citation 密度、零引用小节列表、正文图表引用数 vs figure_bank/table_bank 规模。
- **redundancy**：小节间 embedding 相似度（`harness.agents.relevance.EmbeddingScorer`），off-diagonal mean/max + top-3 相似小节对。单测不许下载模型：用 keyword fallback 模式或 stub scorer。

### L2' `corpus_coverage` — corpus-grounded coverage（新领域可用的覆盖层）

- 数据源：`Taxonomy.categories`（每类含 `category_name`/`description`/`paper_ids`，P5 已产出）× 综述小节文本。
- 方法：embedding 对齐（category name+description vs section text，`EmbeddingScorer`）。每类判 covered = best-match 相似度 ≥ `EVISURVEY_EVAL_COV_MIN`（默认 0.5）。
- 每类同时算 **citation_depth** = 该类 `paper_ids` 被正文引用的比例。
- 汇总：`category_coverage_rate`（covered 类 / 全部类）、按类论文数加权的 depth、missed categories 列表、`corpus_utilization` = 正文引用过的 papers / paper_cards 总数。
- gold `reference_coverage` 保留不动：`cache/gold_refs.json` 存在才跑（现状已如此），报告中作为可选对照。

### L1.5 `uncited_claims` — 未引用句验证（贵层，可跳过、可续跑）

- 抽取无有效引用的正文句（复用 `_iter_sentence_claims` 的反集）→ 逐 claim 调 `sciverse.agentic_search(claim, top_k=3)` → hits 的文本句窗化后过 NLI（复用 `_evidence_units` + `_best_judgment`）→ supported/weak/unsupported。
- 预算：`--max-uncited-claims`（默认 60，超出截断并计数）+ 既有 `SCIVERSE_MIN_INTERVAL` 限速。
- 续跑：结果按 claim 文本缓存到 `output/uncited_claim_cache.json`；重跑命中缓存的不发检索请求（单测用 stub 计数验证第二次 run 零新增调用）。
- 汇总：`uncited_support_rate`（supported / 总 uncited claims）；headline 指标 `overall_unsupported_rate` = (cited unsupported pairs + uncited unsupported claims) / (cited pairs + uncited claims)。

### L3 `academic_value` — DeepSurvey 三维 judge（替换现有 7 维 rubric）

- 三维（DeepSurvey-Bench 标准）：**informational value**（核心研究目标与关键内容的信息量）、**scholarly communication value**（结构组织与学术表达）、**research guidance value**（批判性分析与研究空白/未来方向）。每维 1–5 + 一行 rationale。
- 调用方式：whole-doc，每维一次 `json_chat`（共 3 次），prompt 带 1/3/5 分档锚点描述。解析失败 fail fast（保持现有 llm_judge 的 raise 行为）。
- 旧的 `JUDGE_DIMENSIONS` 七维 rubric 删除（被三维覆盖：logic/clarity/coverage/relevance 并入三维的锚点描述）。

## 入口与开关

- 新 flags：`--skip-uncited`、`--max-uncited-claims`、`--cov-threshold`；`--skip-judge` 同时跳过 L3。
- `--skip-uncited` 路径不得 import sciverse client（保持离线可跑）。
- `render_md` 区块顺序：Deterministic Profile → Faithfulness（citation_quality + uncited_claims）→ Coverage（corpus_coverage + 可选 gold）→ Academic Value → A/B 表（保留）。
- 真跑命令不变：`EVISURVEY_REAL_NLI=1 python scripts/run_survey_eval.py --evidence-store cache/eval_evidence_store.json`。

## 验收条件

worktree 内判定（零网络，fake LLM / FakeNLI / stub sciverse）：

1. `pytest tests/unit/` 全绿。
2. 四层各至少一条精确数值断言的正例单测（fixture markdown + fixture artifacts）。
3. uncited 续跑：同一 fixture 第二次 run，stub 检索计数为零新增。
4. `--skip-uncited` 下脚本不构造 sciverse client；`--help` 正常。
5. citation_quality / reference_coverage / ab_comparison 存量断言保持绿。

合并后主工作区判定（主会话做，一次）：`EVISURVEY_REAL_NLI=1` 对现有 output/cache 产物跑全量，产出四区块报告，目检数值合理、无静默降级。

## 边界 / 不做

- 不做 AHA、pairwise、SurGE 跑分。
- 不动生成侧；不改 `EvidenceStore`/`Taxonomy` 等 artifact 模型。
- 不做跨 run 指标对比存储（那是"迭代信号"定位的需求，本次定位是交付背书）。
