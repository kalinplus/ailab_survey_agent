# T3 写作变化性（综述修辞改造，消除模板填充感）

Status: dispatching (2026-09-04 晚)

## Motivation

S0 评测：冗余 max 0.961（OC×FD）、0.898（Abstract×Intro）、正文间 0.885；
L3 judge 点名 "repetitive boilerplate / meta-commentary"。用户要求：实际
撰写不能只是填充模板。学术综述写作研究结论（Waterloo/Monash 写作中心、
Purdue OWL、Mensch & Kording 2017）：

- **按主张组织，不按论文罗列**：serial per-paper 摘要是 annotated
  bibliography 反模式——当前 [SUMMARY] 恰是此形态。
- **让文献互相对话**：一致、冲突、缺口，而不是逐篇总结。
- **引用风格混合**：author-prominent（标题作主语，突出地标/争议工作）与
  information-prominent（公认结论句尾聚簇挂引）交替。
- **段落 = 一个主张**，句子层面 reporting verb / 过渡语要变化。

## Boundary（触达文件）

- `tools/write_survey.py`（节内修辞结构 + OC/FD 数据源分离 + Abstract/Intro 差异化）
- `tests/unit/test_c_tools.py`（既有文件内加用例）
- **不碰**：`tools/phases/`、`harness/citation_prelock.py`、
  `tools/evaluate_survey.py`、`PROGRESS.md`、`specs/`。

## Slices

1. **正文节修辞改造**：固定三段（SUMMARY/COMPARISON/LIMITATION）改为
   moves 菜单驱动——GLM prompt 给出该节的写作 moves（按主张分组综述 →
   对比/冲突 → 缺口收尾），不再固定段落标签；factual 句仍须近乎逐字
   拼装 evidence snippet 并挂 `[Pn]`，修辞/过渡句无引用、不受 NLI 约束。
   硬约束保留：引用只出自本节白名单；同模板句不得跨节复用。
2. **引用风格混合**：prompt 要求地标工作用 author-prominent（论文标题入句 +
   挂 tag）、公认结论用 information-prominent（句尾多 tag 聚簇）；
   `_map_alias_citations` 的归位逻辑兼容两种形态。
3. **OC / FD 数据源分离**：OC = GLM 汇总各节缺口（输入：各节 selected
   papers 的 limitation 字段 + 证据句，输出跨节综合的 open problem 句，
   每句挂来源 tag）；FD = 逐方向可操作建议（输入：limitation 证据 +
   contribution 字段），两者不得使用相同证据句集合。
4. **Abstract / Intro 差异化**：Abstract = LLM 生成的覆盖范围 + 证据方法
   摘要（挂 2-3 个白名单引用）；Intro = 研究动机 + taxonomy 路线图
   （逐节一句话预览，从 section plan 生成）。不再共用静态模板。

## Acceptance Criteria（unit，fake LLM，无网络）

1. 跨节唯一性：对 ≥3 节的 plan，断言任意模板/生成句不出现在 ≥2 个正文节
   （排除 References）；OC 与 FD 的证据句集合交集为空。
2. 引用风格：fake LLM 回复含 author-prominent（标题入句）与句尾聚簇两种
   形态，断言均能绑定到白名单 id；`…scale. [paper:x].` 归位逻辑不回归。
3. Abstract 含 ≥1 合法引用；Intro 含每个正文节标题的预览句。
4. off 模式（EVISURVEY_WRITER_LLM unset）模板路径仍产出合法结构（既有
   测试全绿；模板文本允许变化）。
5. `pytest tests/unit/` 全绿。

## Real-API Acceptance（S0 下轮真跑，主会话）

L0 max sim < 0.8（OC×FD、Abstract×Intro 不再进 top pairs）；L3 judge
rationale 不再点名 repetitive boilerplate / meta-commentary。
