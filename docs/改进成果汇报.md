# EviSurvey v2 改进成果汇报

上海人工智能实验室 2026 暑期夏令营 · Task 4（World Models / GameCraft）· 2026-09-08 → 2026-09-11

## 一、我们做了什么

EviSurvey 是一条**证据接地的综述自动生成流水线**：给定 topic，真实检索文献（SciVerse + MinerU PDF 解析）、提取原子命题并逐字绑定证据、受契约约束地写作、NLI 逐句验证、按失败类型修复、渲染图文并茂的 HTML/PDF 综述。v2 阶段围绕一个目标：**让"每一句可溯、每一引真实"从口号变成机制**。四项核心工作：

### 1. 反幻觉证据契约（最大改动）
- 每条命题携带三件套：来源角色（own_method/own_result/own_limitation…）、逐字摘录 `source_quote`、真实证据块 ID；
- 命题必须通过 NLI 闸（命题 vs 自证原文）才可进入写作来源池；终验时 claim mapper **逐字复核**绑定关系——侧门喂入一律判废；
- 论文元数据只来自 API 结果，永不 LLM 生成；图表只从解析结果开采，生成图表只由已验证内容派生。

### 2. 有界 Agent 关节（策略 / 修复 / 闸门）
- **策略 Agent**：探测→聚类→命名→抽样→自我修正（≤3 轮）+ 确定性闸门与最优回退；
- **修复 Agent**：验证失败按 A–F 类型分组，LLM 批量选择动作（重映射/改写/换证据/补证据/删除为最后手段），改写句增量重过 NLI；
- **Goal Gate**：三道闸（非法引用=0、unsupported 清零或预算尽、覆盖率 ≥0.7 拦"越修越空"）+ 不动点检测 + best-so-far 回滚，失败以 `quality_failed` 非零退出**诚实收场**。

### 3. 写作契约与鲁棒性
- 结构化 JSON 写作 + 多层校验（引用别名归一化、scope↔角色映射、单句、禁语），任何整体失败回退确定性模板（诚实降级）并**落盘原始回复与拒绝原因**，回退可归因；
- 模型路由：生成类走 DeepSeek Flash（thinking disabled，实测 0 空回复、3.4s/卡），轻量校验走 Intern-S2；
- P2 种子骨架占位描述治理——一个修复同时消灭正文泄漏与"综述方法论"论文污染引用集。

### 4. 管线健壮性
- MinerU 任务台账/断点续轮询/结果缓存（冷跑 64s/篇→暖跑零 HTTP）；SciVerse `/content` 全文通道省 1/4 MinerU 调用；三道主题闸门（域黑名单、负模式锚定、bge 相似度 0.60 精确拐点+主题词豁免+fail-open）；经典论文种子注入；PDF 表格跨页渲染（续页自动重复表头）。

## 三、已知局限（诚实声明）

- 正文 LLM 散文存活率仍受限（9 个写作单元 4 个存活，其余回退到事实安全但文风呆板的模板句），当前瓶颈在装配层防御，已列下一波；
- topic_relevance 0.656<0.7：引用集已去污，剩余拖分来自章节-论文分派的关键词弱匹配错位；
- Future Directions 节依赖 own_limitation 提取，目前每轮仅 0–2 条过闸，常为空；
- canonical/gold 文献覆盖有白名单 cap 15 的结构性上限。
